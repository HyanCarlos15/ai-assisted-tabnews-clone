# Contexto do Projeto: ai-assisted-tabnews-clone

Este projeto é uma implementação (clone) do [TabNews](https://www.tabnews.com.br) desenvolvida durante o [curso.dev](https://curso.dev), construída com o auxílio de agentes de IA.

## Stack Tecnológica
- **Framework**: Next.js (App Router)
- **Biblioteca UI**: React

## Comandos
- `npm run dev`: Inicia o servidor de desenvolvimento.
- `npm run build`: Gera o build de produção da aplicação.
- `npm run start`: Inicia o servidor de produção (após o build).
